NH Interactive — Shop + Whole Sets v2

What changed:
- Hoodie and Pants remain separate shop items.
- Whole Set 01, 02, and 03 are now real shop items.
- Whole Sets only appear in the Whole Set section of Inventory after purchase.
- Buying does NOT automatically equip a Whole Set.

- Equipping a Whole Set replaces separate Top/Pants mode.
- Equipping Hoodie or Pants exits Whole Set mode.
- Whole Set prices are temporary placeholders (1,000 coins each) so the purchase flow can be tested.
- We can change all prices later.
